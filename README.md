# Dev Toolbox

ブラウザ内で処理が完結する、開発者向けユーティリティ集です。
入力した値は外部に送信されません。入力はタブ内（sessionStorage）にだけ保持され、ブラウザを閉じた後まで残す保存はしません。タブを閉じると通常は消えますが、ブラウザのセッション復元で戻る場合があります。

**公開ページ**：https://0naoki.github.io/page.developer-toolbox/

正式な公開先はこのアドレスだけです。ほかの場所にある同じ名前のページは、このリポジトリが公開したものではありません。入力する前に、アドレスを確かめてください（[セキュリティポリシー](SECURITY.md#正式な公開先)）。

## 技術構成

- React 19 + TypeScript 7 + Vite 8
- React Router 7（HashRouter：GitHub Pages でのリロード時 404 を回避）
- Vitest（ロジックの単体テスト）、Playwright（本番ビルドのブラウザテスト）
- GitHub Actions：CI・CodeQL・Dependency review・GitHub Pages への自動デプロイ、Dependabot による依存更新

## 起動する

Node.js 22.12 以上が必要です（推奨は `.nvmrc` のバージョン）。

```bash
npm ci
npm run preview:pages
```

[本番相当の画面](http://localhost:4173/dev-toolbox/)を開きます。停止は起動したターミナルで `Ctrl+C` です。Windowsでは `start.ps1` でも起動できます。準備・スクリプトの使い方・開発サーバーの起動は [ローカル確認手順](docs/LOCAL_CHECK.md) を参照してください。

## セキュリティ

処理はブラウザ内で完結し、本番ではCSPで通信やHTMLの挿入を制限します。入力は localStorage に保存せず、トークン・鍵などの機密値はタブ内にも保存しません。

保存・消去の操作は [利用ガイド](docs/USAGE.md)、CSPで防げない経路やセッション復元などの制約、脆弱性の報告窓口は [SECURITY.md](SECURITY.md) を参照してください。

## 結果を利用する前に

JWT・証明書の署名の一致は、利用先での受け入れや証明書の信頼性を保証するものではありません。判定の範囲、入力上限、祝日・日時などの制約は [利用ガイド](docs/USAGE.md) を参照してください。
